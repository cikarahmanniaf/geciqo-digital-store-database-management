# Geciqo Database Management

## Deskripsi

Repository ini berisi **Final Project Mata Kuliah Basis Data** mengenai rancangan manajemen database produk digital pada Toko **Geciqo** menggunakan **DBMS MySQL**.

Project ini berfokus pada perancangan sistem basis data yang dapat digunakan untuk mengelola data produk dan transaksi pada Toko Geciqo. Perancangan dilakukan dengan menentukan komponen-komponen basis data, hubungan antar-entitas, ER Diagram, serta proses normalisasi tabel.

Selain perancangan struktur basis data, project ini juga mencakup implementasi **procedure** dan **trigger** untuk mendukung proses penambahan dan pengurangan stok produk serta pembuatan nota sebagai salah satu luaran dari sistem.

## Tujuan

Project ini bertujuan untuk:

1. Menentukan komponen-komponen dalam perancangan basis data Toko Geciqo.
2. Menentukan hubungan antar-entitas melalui ER Diagram serta melakukan proses normalisasi tabel.
3. Membuat prototype rancangan basis data beserta luaran formulirnya.
4. Mengimplementasikan **procedure** dan **trigger** untuk proses penambahan dan pengurangan stok produk.
5. Membuat nota berdasarkan data transaksi yang tersimpan dalam database.
